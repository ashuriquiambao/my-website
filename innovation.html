Our Innovation

NIKEDO presents a future laptop designed to automatically close itself when the user is no longer present.

💻 NIKEDO Self-Closing Laptop

NIKEDO is an innovative laptop concept designed to help protect the device and improve convenience. The laptop uses a camera or sensor to detect whether the user is still present in front of the device.

🎯 Purpose of the Innovation

The main purpose of NIKEDO is to create a laptop that can automatically close when the user leaves. This can help prevent the laptop from being left open and can provide an additional layer of convenience for users.

⚙️ How It Works

1. User Detection

A camera or sensor detects whether the user is present in front of the laptop.

2. One-Minute Timer

If the system detects that the user has left, it starts a one-minute timer.

3. Automatic Closing

If the user does not return after one minute, the laptop is designed to automatically fold or close.

4. User Returns

If the user returns before the timer finishes, the closing process can be stopped.

💡 Benefits

• Helps prevent the laptop from being left open.

• Provides a convenient automatic closing feature.

• Can help improve user awareness and device care.

• Introduces a creative combination of sensors and automatic movement technology.

📦 Prototype

For our prototype, we can create a physical model of the laptop using cardboard and other available materials. The prototype will demonstrate the concept of a laptop that can detect when the user is absent and automatically close after one minute.

🚀 Future Development

In the future, the NIKEDO concept could be improved by using real sensors, a motorized hinge, and a programmed control system. These components could allow the concept to move from a simple prototype into a functional device.
